# Eliáš Procházka

Zdrojový kód mého osobního webu a portfolia. Žádné zbytečnosti.

Pokud vás zajímá, jak to celé funguje, kód je plně open-source.

## Stack

- Next.js 15
- React 19
- Tailwind CSS
- Framer Motion

## Design & Architektura

Snažil jsem se vyhnout klasickým šablonám. Všechny animace (jako dynamické podtržení a zakroužkování textu) jsou tvořeny vlastnoručně pomocí SVG a Framer Motion – žádné přebytečné knihovny.

Konfigurace celého obsahu žije odděleně v `config/site.tsx`, zbytek je jen striktně typovaný TypeScript a funkční komponenty.
